# Changelog 📜

All notable changes to **DeepSeek Orbit** will be documented in this file.
The project adheres to [Semantic Versioning](https://semver.org/).

---

## [2.0.0] - 2026-09-02

### 🧠 Persistent Instructions & Persona Memory Studio
- **Multi-Persona Memory Studio:** Create, edit, activate, and manage persistent system instructions and specialized developer personas directly on DeepSeek.
- **Prompt Action Bar Integration:** Mounts an interactive `Memory` toggle button directly next to DeepThink and Search on the bottom prompt toolbar.
- **Persian & English Presets:** Built-in curated instructions for Senior Full-Stack Engineering, Clean Code Arch, Fluent Persian localization, and more.
- **In-Place Non-Disruptive Editing:** Smooth in-place editor view matching DeepSeek's native dark palette with zero layout shifting.

### 📥 Context Ingest Studio (Codebases, Repos & Web)
- **Local Folder Ingestion:** Ingest entire multi-file project directories with automatic tree visualization, file filtering, and token estimation.
- **GitHub Repository Ingestion:** Fetch public repositories directly via GitHub API with branch selection, subfolder filtering, and token counts.
- **Web Page Content Extractor:** Fetch clean text content from articles and documentation URLs directly into the prompt box.

### 📊 Dynamic Interactive Markdown Tables
- **1-Click Export:** Download any markdown table as Excel (`.xls`) or copy formatted CSV data directly to your clipboard.
- **Interactive Multi-Column Sorting:** Sort table rows dynamically by clicking any column header with visual ascending/descending indicators.

### 📦 Multi-File 1-Click ZIP Scaffolder & Live Preview
- **Multi-File ZIP Bundler:** Detects multi-file projects generated by DeepSeek in markdown code blocks and bundles them into an instant `.zip` download.
- **Live Sandbox Preview Artifacts:** Interactive iframe preview for HTML/CSS/JS code with real-time responsive viewport toggles (**Desktop**, **Tablet**, **Mobile**).

### 🖥️ Wide Chat Mode & Textarea Expander
- **Wide Chat Mode:** Widescreen `1200px` layout option in dashboard and floating toolbar with fluid `0.35s` transitions.
- **Textarea Expander:** Smoothly expand the prompt textarea up to `60vh` while keeping all bottom action buttons docked and visible.
- **Scroll to Top of Message:** Added a 1-click navigation button on message action bars to jump directly to the top of lengthy responses.

## [1.5.0] - 2026-08-31

### 🌟 Branding & Visual Identity
- **New Name & Visuals:** Officially launched as **DeepSeek Orbit — Smart Workspace & RTL Flow**.
- **Custom 3D Glassmorphic Icon:** Designed and rendered custom high-contrast DeepSeek royal blue whale and cyan neural waveform app icons (`16x16`, `48x48`, `128x128`).
- **Hero Banner:** Added high-resolution repository hero banner with glowing orbital theme.

### 🎨 Custom Wallpaper Studio & Theming
- **Custom Wallpaper Engine:** Support for uploading custom high-resolution background wallpapers with persistent `chrome.storage.local`.
- **Wallpaper Controls:** Real-time opacity slider (5%–60%) and background blur slider (0px–20px) with smooth CSS transitions.
- **DeepSeek Native Transparency:** Full glassmorphism for message bubbles, thinking accordions, user action bars, and bottom masks while preserving native sidebar colors.
- **Centered Wallpaper Studio:** Dedicated centered dialog on DeepSeek for seamless drag & drop file uploads and live adjustments.

### 📌 Navigation & Pin System
- **Unified Pushpin Icon:** Refreshed modern diagonal pushpin SVG with synchronized shape across pinned and unpinned states.
- **Active State:** Pinned state smoothly lights up in DeepSeek Royal Blue (`#4d6bfe`).
- **Mini-Nav Scrollbar Containment:** Fixed premature scrollbar popups on the right-side prompt history mini-nav by strictly binding to DeepSeek's `._7a8ea4` hover state.

### ⚡ Developer & Modal Improvements
- **Smooth Code Modal Animations:** GPU-accelerated enter and exit transitions for fullscreen code view (`scale(0.95) translateY(10px)` with ease).
- **Code Block Border Radius:** Preserved crisp rounded borders on all `.md-code-block` elements when custom wallpapers are active.
- **Smooth Export Menu:** Added cubic-bezier ease transitions to the floating export menu dropdown.
